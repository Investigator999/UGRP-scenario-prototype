# UGRP scenario prototype

A working, bilingual (Arabic and English) end-to-end scenario for Qatar's Unified Government Resource Planning (UGRP) programme: budget circular and ceilings, entity proposal, MoF approval, purchase requisition with funds check, quotations and PO, goods receipt, 3-way invoice match, payment by signatory band, and the budget and cash position.

Each step shows the UGRP process it covers, the GRP capability it needs (on any ERP platform), and agreed test criteria. Key users agree to each step or request changes, and the Implementation baseline tab turns their sign-off into agreed scope the implementation team can start fit-gap and configuration from.

Live: https://ugrp-eight.vercel.app

The whole prototype is a single file, `index.html`, with no build step. Figures, entity and suppliers are illustrative.
